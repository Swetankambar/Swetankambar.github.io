# Samvet - Personal Blog

[My Personal Website](https://swetankambar.github.io/)

## About

Ensemble of my thoughts, experiments and observations.

This site has been migrated from Hugo to Astro for better performance and modern developer experience.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Tech Stack

- **Framework**: Astro
- **Deployment**: GitHub Pages via GitHub Actions
- **Content**: Markdown with frontmatter

## Content Categories

- **Junkomics**: Comics and visual stories
- **Perspectives**: Philosophical thoughts and reflections
- **RF Playground**: RF engineering experiments
